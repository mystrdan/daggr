# daggr — Domain Market Explorer

Rebuilt from zero as an onchain-style domain market explorer.

Reference model: DEX Screener, Birdeye, DEXTools and blockchain explorers — discovery, dense market tables, filters, pagination, activity and source navigation. Daggr is not a copy of their UI or branding.

Rules: real data only; main feed floor $10; pagination; active source links open in a new tab; five-source news sidebar; source adapters separated from UI; domain assets can carry network/contract/token identifiers.
